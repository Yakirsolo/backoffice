I want to redesign the **entire website**, not just make small UI improvements.

This is a **professional back-office system for a nutrition coach**, and the current design feels too basic, generic, and closer to an internal prototype than a polished professional SaaS product.

### Main goal

Redesign the whole application so it feels like a **modern, premium, professional management platform**.

The application is in **Hebrew**, so the design must be **RTL-first**. Do not design an English/LTR interface and simply mirror it. The layout, spacing, hierarchy, navigation, tables, forms, icons, dropdowns, and interactions should all feel intentionally designed for Hebrew RTL.

### Design direction

I want the application to feel:

* Professional
* Modern
* Premium
* Clean
* Minimal
* Organized
* Trustworthy
* Easy to use
* Consistent
* Like a real commercial SaaS product

It should **not** feel:

* Like a basic CRUD dashboard
* Like a developer-built admin panel
* Overly colorful
* Overly complicated
* Full of unnecessary cards
* Like a generic Bootstrap/Material UI template
* Like every piece of information is placed inside a separate bordered box

Think about the quality level of modern professional products such as Linear, Notion, Stripe, Monday, HubSpot, or other polished SaaS back-office systems — but adapt the visual language to a **nutrition coaching business** and keep it appropriate for Hebrew RTL.

* Spacing

Every screen should look like it belongs to the **same professional product**.

### Layout

Create a strong application shell.

I want:

* A professional RTL sidebar/navigation
* Clear separation between navigation and content
* A clean top/header area where appropriate
* Consistent page width and content alignment
* Excellent whitespace
* Clear visual hierarchy
* Responsive behavior
* Consistent page headers
* Consistent action placement

The sidebar should not feel like a generic admin template. It should feel like part of the product's identity.

### Dashboard / Overview

The dashboard should immediately communicate the important information.

Avoid simply putting many cards next to each other.

Instead, think about:

* What information is most important?
* What should the coach see immediately?
* What requires attention?
* What changed recently?
* Which clients need attention?
* What upcoming actions exist?
* What are the important business metrics?

Use hierarchy rather than giving every piece of information equal visual weight.

### Clients

The clients section is one of the most important parts of the application.

It should feel like a professional **client management system**, not a basic database table.

Think about:

* Professional client list
* Search
* Filters
* Status
* Quick actions
* Client profile
* Important client information
* Progress
* Weight history
* Measurements
* Photos
* Agreements
* Nutrition plans
* Payments
* Calls/meetings
* Social links
* Activity/history

The client profile should have a clear information architecture.

Do not put everything on one giant page.

Use tabs/sections where appropriate and make the most important information immediately visible.

### Forms

Forms currently feel too much like basic CRUD forms.

Redesign them to feel intentional and premium.

For example:

Instead of:

`Label → input → Label → input → Label → input`

everywhere, group related information into logical sections.

Use:

* Clear section titles
* Helpful descriptions where needed
* Proper spacing
* Consistent field widths
* Logical grouping
* Clear required/optional states
* Professional validation
* Good empty states
* Proper RTL alignment

The user should understand the structure of the form immediately.

### Tables

Tables should feel modern and readable.

Avoid excessive borders.

Use:

* Strong column hierarchy
* Proper row height
* Subtle separators
* Good typography
* Status badges
* Hover states
* Consistent actions
* Search/filter controls
* Pagination where necessary

Do not make every cell look like a separate box.

### Colors

Keep the color palette restrained.

I want a professional neutral foundation with a carefully chosen primary/accent color.

Use colors intentionally for:

* Primary actions
* Success
* Warning
* Error
* Information
* Statuses

Do not use colors just to make the interface look more interesting.

### Typography

Typography is extremely important because the entire application is Hebrew.

Choose a **high-quality Hebrew-friendly font** and establish a clear typography hierarchy.

Make sure:

* Hebrew looks natural
* Numbers are readable
* Tables are easy to scan
* Headings have strong hierarchy
* Labels don't feel cramped
* Font weights are used intentionally

### Micro-interactions

Add subtle professional interactions where they improve usability:

* Hover states
* Focus states
* Smooth transitions
* Button feedback
* Loading states
* Skeletons where appropriate
* Toast notifications
* Modal transitions
* Dropdown animations

Keep them subtle. The goal is polish, not animation for the sake of animation.

### Icons

Use one consistent icon system.

Do not mix random icon styles.

Icons should support the UI rather than dominate it.

### Empty / Loading / Error states

These are part of the design and should be designed professionally.

Do not leave blank white areas or display raw errors.

Create consistent components for:

* No clients
* No data
* No history
* Loading
* Failed requests
* Empty search results

### Responsive design

Make sure the redesign works properly across:

* Desktop
* Laptop
* Tablet
* Smaller screens

This is a back-office application, so desktop is the primary experience, but it should still behave properly on smaller screens.
